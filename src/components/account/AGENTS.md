# Account presentation rules

- Account demos require authenticated preview opt-in and credential-free in-memory records; cards/details navigate to the central V2 guide using only the eSIM identity — why: no purchases, credential URLs or duplicated guides.
- Account summaries use shared categories and refund-window/server-verdict modules; EsimInstallGuide renders protected installation data only, while walkthroughs live on the central V2 page — why: presentation must never infer eligibility, submit refunds or fork installation flows.
- The central walkthrough uses shared StepNavigation with clamped indices, variable step-count sizing and a fixed left-to-right row; steps advance on user selection only — why: stable navigation across RTL and narrow screens.
